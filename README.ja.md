# 英語学習

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md)

Cognis Study 向けの英語学習内容とプロバイダー統合です。

## 同梱学習コンテンツ

書字ガイド、テーマ別の語彙、参照付きの例文、イラスト、初期デッキを提供します。収録内容とメディアのインベントリを、利用可能な項目の参照元とします。

## 機能

- 文字と文字の組み合わせには独自のJSON書字ガイドを用意し、語彙・文法・句読点のカードを文脈のある例文と結び付けます。
- 不規則形と IPA を含む動詞・コピュラ・形容詞の活用群を用意し、非表示の補助カードで文のグラフを保持します。
- 検索可能な無料辞書、定義・読みの上限、非表示の出典情報、ホスト管理のキャッシュを利用します。
- 翻訳済み初期デッキは Cognis のフラッシュカード、お気に入り、共有を利用します。

## インストール

Cognis モジュール市場からこのリポジトリをインストールして有効にします。Study ゲートウェイと `study:library:provider` が必要です。

## 構成

初期化は ctx でプロバイダーを登録し、保護されたパッケージを取り込み、英語記述子と解除可能なフローフックを公開します。無効化はプロバイダーを解除し、アンインストールは Cognis 経由で内容を保持または連鎖削除します。ホスト画面、キャッシュ方針、内部実装は複製しません。

## 音声と録音

同梱WAVはチェックサム・形式・PCMの整合性を確認します。聴取による検証は別に記録し、未検証の場合もあります。`data/audio/recordings.json` は利用可能な録音と結合音声を、`data/audio/unavailable.json` は音声未収録のカードを明示します。未収録の音声に再生URLは設定しません。指定音声は `gJx1vCzNCD1EQHT212Ls` です。認証情報やオフライン生成ツールは同梱しません。

同梱文の再生は選択した活用形も含め、構成要素と同一の PCM を連結した録音を使用します。別生成の文全体の録音は音声とリクエストの来歴を保持したまま一覧に残しますが、合成録音を上書きしません。新しい文はホストによる合成とキャッシュを使用します。

起動時に解除可能な `study:audio:provider.registerProvider` を登録します。同梱カードと派生形はElevenLabsの導入・設定なしで利用できます。未収録の語彙は任意依存の設定済み `elevenlabs-tts:synthesis` を利用できます。要求の既定音声は言語の指定音声で、管理者は新規合成用の音声を変更できます。新しい文を文全体として別途合成しません。Cognisがグローバルカードの権限、キャッシュ、手動アップロード、個人・クラス用の結合方針を管理します。最初に記載された発音のみ選択します。

生成ファイルは24 kHz、モノラル、16ビットPCMで、ピーク制限と無音でないことを検証します。要求は言語別の固定モデル、速度0.9、類似度0.85、スタイル0を使用し、安定度は英語0.75、日本語0.9です。シードは要求ごとに保持し、無音として拒否した出力は声を変更せず再生成します。英語では記載されたIPA音素タグを使用します。コンテンツマニフェストに同梱アセットディレクトリを宣言し、インストール用のパック版を更新します。

## 語彙のイラスト

語彙カードには、色鉛筆・水彩調の生成イラストを追加しました。具体的な物、動作、抽象概念を説明する場面を、既存のカード詳細ギャラリーと画像ポップアップに表示します。従来の出典写真は置き換えました。[画像カタログ](data/library/assets/images/catalog.json)に生成元、画風、切り出し情報、チェックサム、カードとの対応を記録し、[画像ライセンス](data/library/assets/images/LICENSE.md)に同梱画像の扱いを記載しています。画像はローカルから読み込まれ、プロバイダーの再読み込み時もユーザー独自の画像はホストが保持します。

## 身近なものの語彙

家具、衣類、日用品、食べ物の名詞に、4言語の意味、発音リンク、専用録音、「身近なもの」のデッキを追加しました。英語の可算名詞には録音付きの複数形変換を用意し、fish は同形複数、rice は不可算名詞として扱います。日本語の初級者向け表記では、テーブルやコートで使う長音符「ー」を含め、完全な読みを個々のかなへリンクします。

## 録音インベントリ

`data/audio/recordings.json` はインベントリ形式2を使用し、言語・声・モデル・処理設定・総数・用途別索引のパスとハッシュを保持します。`data/audio/indexes/` は `data/audio/inventories/` の分割ファイルをハッシュ付きで列挙し、文字・語彙・活用・文全体・構成語合成の用途に分けます。主索引と用途別索引は400行未満、録音の分割ファイルは800行以下を維持します。読み込み時に両階層のハッシュ、件数、許可パス、用途と種類の対応、重複パスを検証してから再生を登録します。録音オブジェクト、音声バイト列、検索優先順位を保持します。

## 画像ラベルの翻訳と中立的なファイル名

画像ファイル名と ID は SHA-256 ハッシュを使用し、元シートの識別子も出典のハッシュを使用します。カタログのメタデータはカードに既存の意味からドイツ語・英語・インドネシア語・日本語のラベルを提供します。表示ラベルと中立的な保存識別子を分離しました。画像データとカード ID は維持し、コンテンツ改訂ですべての画像参照を更新します。

## 最終レビューと無効な言語へのアクセス

アンインストールでは学習内容を保持する場合も音声設定を削除します。無効化するとモジュールのルート、静的 UI、プロバイダー登録を解除します。設定は無効化と再起動をまたいで保持し、有効な間だけ提供します。Cognis は稼働中の言語プロバイダーに基づいて保存済みスキーマ・カード・メディアへのアクセスを制限し、再有効化で復元します。参照検索は同一の出典識別子を統合し、元レコード、読み順、意味を保持します。同梱文は構成要素と同一の PCM 合成録音を優先し、直接録音も別途保持します。音声生成前に正規化済みの文字種と長さを検証します。KanjiVG の失敗応答は破棄し、長音符にも対応します。

語彙一覧はすべての品詞を表示した状態で開始します。品詞フィルターは任意で選択・解除でき、名詞の選択を必須にしません。コンポーザーで使う語彙も Cognis の一覧では通常の語彙として扱います。

文構造カルーセルは `excludeFromBrowse: false` を明示し、その語彙を「語彙」にも表示します。句読点専用カルーセルは除外したままです。テストでは全文の語彙参照、非表示の発音別名、任意フィルターの対象範囲を確認します。

## 学習者向けタグの整理

英語カードのピルは、内部の変形・語形タグではなく、意味のある翻訳済みメタデータを表示します。品詞の選択肢とフィルターは翻訳した名前とプロバイダーの定義順を使います。任意のフィルターは値が一つでも未選択から始まり、保存タグと生成変形は保持します。

## 汎用の難易度プロファイル

両方の Study モジュールは共通の `difficulty_level` フィールドを使います。同一の正規化処理と契約テストが `data/library/difficulty.json` を読み、表示名、選択肢の順序、出典タグの対応、基本レイヤーの既定値、変形の難易度をデータとして扱います。日本語は JLPT N5～N1、英語は既存の初級・中級・上級を表示します。不明な値は未分類のままです。ホストは言語固有の規則や別名フィールドを使わず、宣言されたフィールドを順位付けします。
