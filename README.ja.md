# 英語学習

Cognis Study の言語パックで英語の文字、単語、文を学習できます。

## できること

英語の学習レイヤーを参照し、関連する項目を調べ、初期デッキで練習し、用意された発音音声を聞けます。

## 始める前に

管理者が言語パックを有効にする必要があります。ログインして Study で英語を学習言語に登録します。辞書や任意の音声サービスは別途設定が必要です。

## はじめに

Study で英語を選び、Explore でレイヤーを開きます。項目を開いて読み、意味、関連内容を確認し、デッキ練習には Flashcards を使います。
