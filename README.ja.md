# 英語学習

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md)

Cognis Study 向けの英語学習内容とプロバイダー統合です。

## 機能

- 独自の JSON 書字ガイドを備えた文字 52 枚と組み合わせ 17 枚、初級語彙 123、文法・句読点 21、参照付きの文 45 を収録します。
- 不規則形と IPA を含む動詞・コピュラ・形容詞の活用群 37 個を用意し、非表示の補助カードで文のグラフを保持します。
- 検索可能な無料辞書、定義・読みの上限、非表示の出典情報、ホスト管理のキャッシュを利用します。
- 七つの翻訳済み初期デッキは Cognis のフラッシュカード、お気に入り、共有を利用します。

## インストール

Cognis モジュール市場からこのリポジトリをインストールして有効にします。Study ゲートウェイと `study:library:provider` が必要です。

## 構成

初期化は ctx でプロバイダーを登録し、保護されたパッケージを取り込み、英語記述子と解除可能なフローフックを公開します。無効化はプロバイダーを解除し、アンインストールは Cognis 経由で内容を保持または連鎖削除します。ホスト画面、キャッシュ方針、内部実装は複製しません。

## 音声と録音

パックには、発音を持つすべての厳選カード、文字、助詞、およびスキーマで到達可能な派生形の検証済みWAV音声を含みます。複数形や複数段階の動詞活用も対象です。`gJx1vCzNCD1EQHT212Ls` がこの言語の指定音声です。`data/audio/recordings.json` に各要求、音声、モデル、設定、活用経路、ファイルのチェックサムを記録します。認証情報や生成ツールは同梱しません。

文には、選択された活用形を含む構成単語・助詞の録音を順番に並べ、そのPCMサンプルをそのまま使用します。このため、同梱文の声と発音は単語の個別再生と一致します。新しい文にはホストの結合処理を使用し、派生形の録音がない場合に基本形の発音で代用しません。対象は厳選パックであり、必要時に読み込む辞書の全項目や任意のユーザー作成文ではありません。

起動時に解除可能な `study:audio:provider.registerProvider` を登録します。同梱カードと派生形はElevenLabsの導入・設定なしで利用できます。未収録の語彙は任意依存の設定済み `elevenlabs-tts:synthesis` を利用できます。要求の既定音声は言語の指定音声で、管理者は新規合成用の音声を変更できます。新しい文を文全体として別途合成しません。Cognisがグローバルカードの権限、キャッシュ、手動アップロード、個人・クラス用の結合方針を管理します。最初に記載された発音のみ選択します。

生成ファイルは24 kHz、モノラル、16ビットPCMで、ピーク制限と無音でないことを検証します。要求は言語別の固定モデル、速度0.9、類似度0.85、スタイル0を使用し、安定度は英語0.75、日本語0.9です。シードは要求ごとに保持し、無音として拒否した出力は声を変更せず再生成します。英語では記載されたIPA音素タグを使用します。コンテンツマニフェストに同梱アセットディレクトリを宣言し、インストール用のパック版を更新します。
