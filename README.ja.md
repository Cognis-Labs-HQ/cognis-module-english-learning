# 英語学習

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md)

Cognis Study 向けの英語学習内容とプロバイダー統合です。

## 機能

- 独自の JSON 書字ガイドを備えた文字 52 枚と組み合わせ 17 枚、初級語彙 192、文法・句読点 21、参照付きの文 49 を収録します。
- 不規則形と IPA を含む動詞・コピュラ・形容詞の活用群 37 個を用意し、非表示の補助カードで文のグラフを保持します。
- 検索可能な無料辞書、定義・読みの上限、非表示の出典情報、ホスト管理のキャッシュを利用します。
- 十個の翻訳済み初期デッキは Cognis のフラッシュカード、お気に入り、共有を利用します。

## インストール

Cognis モジュール市場からこのリポジトリをインストールして有効にします。Study ゲートウェイと `study:library:provider` が必要です。

## 構成

初期化は ctx でプロバイダーを登録し、保護されたパッケージを取り込み、英語記述子と解除可能なフローフックを公開します。無効化はプロバイダーを解除し、アンインストールは Cognis 経由で内容を保持または連鎖削除します。ホスト画面、キャッシュ方針、内部実装は複製しません。

## 音声と録音

パックには、発音を持つすべての厳選カード、文字、助詞、およびスキーマで到達可能な派生形の検証済みWAV音声を含みます。複数形や複数段階の動詞活用も対象です。`gJx1vCzNCD1EQHT212Ls` がこの言語の指定音声です。`data/audio/recordings.json` に各要求、音声、モデル、設定、活用経路、ファイルのチェックサムを記録します。認証情報や生成ツールは同梱しません。

同梱文は直接生成した文全体の録音を結合音声より優先します。新しい文や録音のない文には、構成要素の PCM と選択した活用形を順序通りに使うホストの結合処理を適用し、派生形の欠落を基本形で代用しません。対象は厳選パックであり、辞書の全項目や任意のユーザー作成文ではありません。

起動時に解除可能な `study:audio:provider.registerProvider` を登録します。同梱カードと派生形はElevenLabsの導入・設定なしで利用できます。未収録の語彙は任意依存の設定済み `elevenlabs-tts:synthesis` を利用できます。要求の既定音声は言語の指定音声で、管理者は新規合成用の音声を変更できます。新しい文を文全体として別途合成しません。Cognisがグローバルカードの権限、キャッシュ、手動アップロード、個人・クラス用の結合方針を管理します。最初に記載された発音のみ選択します。

生成ファイルは24 kHz、モノラル、16ビットPCMで、ピーク制限と無音でないことを検証します。要求は言語別の固定モデル、速度0.9、類似度0.85、スタイル0を使用し、安定度は英語0.75、日本語0.9です。シードは要求ごとに保持し、無音として拒否した出力は声を変更せず再生成します。英語では記載されたIPA音素タグを使用します。コンテンツマニフェストに同梱アセットディレクトリを宣言し、インストール用のパック版を更新します。

## 語彙のイラスト

同梱されるすべての語彙カードに、それぞれ固有の色鉛筆・水彩調の生成イラストを追加しました（192件）。具体的な物、動作、抽象概念を説明する場面を、既存のカード詳細ギャラリーと画像ポップアップに表示します。従来の出典写真は置き換えました。[画像カタログ](data/library/assets/images/catalog.json)に生成元、画風、切り出し情報、チェックサム、カードとの対応を記録し、[画像ライセンス](data/library/assets/images/LICENSE.md)に同梱画像の扱いを記載しています。画像はローカルから読み込まれ、プロバイダーの再読み込み時もユーザー独自の画像はホストが保持します。

## 身近なものの語彙

家具、衣類、日用品、食べ物の名詞15件に、4言語の意味、発音リンク、専用録音、「身近なもの」のデッキを追加しました。英語の可算名詞には録音付きの複数形変換を用意し、fish は同形複数、rice は不可算名詞として扱います。日本語の初級者向け表記では、テーブルやコートで使う長音符「ー」を含め、完全な読みを個々のかなへリンクします。

## 食べ物と体の語彙

食べ物16件と体の部位16件、計32件のイラスト付き名詞に、4言語の意味と「食べ物」「体」の学習デッキを追加しました。英語には feet、teeth、potatoes、有声子音を持つ mouths など25件の録音付き数変換を用意し、鶏肉、牛肉、バター、肌などの不可算名詞の意味には複数形を設けません。日本語では個々のかなへ至る完全なリンクを保ち、「あし」の足と脚の意味を別々の定義に分け、発音入力が同じ場合は既存のネイティブ音声を再利用します。各言語に個別に作成した例文4件を追加し、直接生成したニューラル録音を、構成要素の録音をそのまま連結する代替音声より優先します。すべてのイラストを従来の言語別の画風でローカルに同梱しています。

## 録音インベントリ

`data/audio/recordings.json` は、言語、音声、モデル、共通の処理設定、件数、整合性検証付きインベントリのパスを保持する小さなマニフェストです。`data/audio/inventories/` 以下で文字、語彙、活用形、直接録音した文、構成要素を連結した代替音声を用途別に分けます。各ファイルは800行未満とし、正確な要求、クリップごとの音声の出所、活用経路、音声チェックサムを保持します。起動時にすべてのチェックサムと件数を検証してから再生を登録し、録音データと検索の優先順は変更しません。

## 明示的なカタログ正規化と文の合成録音一覧

カタログ読み取りは言語プロバイダーから正規化方式を受け取ります。英語は NFC、日本語は NFKC を使用し、共通検索コード内の言語分岐を除去しました。文の合成録音一覧を `sentence-compositions` に改称し、各項目は構成要素のクリップを順番に連結した実際の同梱録音を表します。直接生成したニューラル文録音は別一覧に保持し、再生時に優先します。

## 画像ラベルの翻訳と中立的なファイル名

画像ファイル名と ID は SHA-256 ハッシュを使用し、元シートの識別子も出典のハッシュを使用します。カタログのメタデータはカードに既存の意味からドイツ語・英語・インドネシア語・日本語のラベルを提供します。表示ラベルと中立的な保存識別子を分離しました。画像データとカード ID は維持し、コンテンツ改訂ですべての画像参照を更新します。
