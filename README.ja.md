# 英語学習

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md)

Cognis Study 向けの英語学習内容とプロバイダー統合です。

## 機能

- 独自の JSON 書字ガイドを備えた文字 52 枚と組み合わせ 17 枚、初級語彙 123、文法・句読点 21、参照付きの文 45 を収録します。
- 不規則形と IPA を含む動詞・コピュラ・形容詞の活用群 37 個を用意し、非表示の補助カードで文のグラフを保持します。
- 検索可能な無料辞書、定義・読みの上限、非表示の出典情報、ホスト管理のキャッシュを利用します。
- 七つの翻訳済み初期デッキは Cognis のフラッシュカード、お気に入り、共有を利用します。

## インストール

Cognis モジュール市場からこのリポジトリをインストールして有効にします。Study ゲートウェイと `study:library:provider` が必要です。

## 構成

初期化は ctx でプロバイダーを登録し、保護されたパッケージを取り込み、英語記述子と解除可能なフローフックを公開します。無効化はプロバイダーを解除し、アンインストールは Cognis 経由で内容を保持または連鎖削除します。ホスト画面、キャッシュ方針、内部実装は複製しません。

## 音声と録音

モジュールは `study:audio:provider` に言語を登録し、任意のElevenLabs音声IDを `db:executor` で保存します。空欄の場合は要求の `voiceId` を省略して既定の声を使用します。認証情報、音声検索、テスト音声は独立したElevenLabsモジュールで設定します。言語パックに生成音声やプロバイダーのHTTP実装は含みません。

Cognisは保存済みグローバルカードの権限を確認してから `speech:synthesis` を呼び出します。カードを開くだけでは音声生成しません。管理者は編集時にプレーヤーの隣でグローバル音声を再生成できます。個人・クラスカードは5 MiBまでのアップロードやマイク録音を受け付けます。文は既存の構成カード音声を連続結合する代替機能を維持します。個人・クラスの結合ではプロバイダーの合成を呼び出しません。明示的な録音を優先し、最初に記載された発音のみ使用します。

内容変更時はコンテンツパックのバージョンを上げ、取り込み済みの旧リビジョンとの有効化競合を防ぎます。

ElevenLabsを任意のモジュール依存関係として宣言します。インストール時に音声合成用として選択できますが、未導入でもStudyの有効化と録音・結合音声を使用できます。
