# Menggunakan pustaka Study bersama

**Cabang Fitur:** work

## Materi pembelajaran berbasis kapabilitas

Modul kini memasang paket konten bahasa Inggris deklaratifnya secara atomik melalui kapabilitas `study:library` yang disediakan host dan membaca entri alfabet dari API Pustaka Study bersama. API, penyimpanan, halaman, dan entri navigasi pustaka yang rangkap telah dihapus.

## Dokumentasi dan kontrak

Manifes kini mewajibkan `study:library`, versi modul menjadi 1.2.15, dan dokumentasi terlokalisasi mengarahkan pengguna ke pustaka Study bersama.
