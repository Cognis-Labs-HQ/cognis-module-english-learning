# Englischlernen

Lernen Sie englische Schrift, Wörter und Sätze mit einem Sprachpaket in Cognis Study.

## Möglichkeiten

Durchsuchen Sie englische Lernschichten, prüfen Sie verwandte Einträge, üben Sie mit Startdecks und hören Sie verfügbare Ausspracheaufnahmen.

## Vor dem Start

Ein Administrator muss das Sprachpaket aktivieren. Melden Sie sich an und wählen Sie Englisch in Study als Lernsprache. Wörterbuch und optionale Sprachausgabe benötigen eine eigene Einrichtung.

## Erste Schritte

Wählen Sie Englisch in Study, öffnen Sie Explore und eine Schicht. Öffnen Sie einen Eintrag für Aussprache, Bedeutung und Beziehungen; verwenden Sie Flashcards für Deckübungen.
