# Cognis English モジュール

Cognis English モジュールは、アルファベットデータ、読み取り専用の学習ライブラリ、クラスルームへの入口を含む、インストール可能な英語学習環境を Cognis Study ゲートウェイに提供します。

## 使用例

- `/study/alphabet` を開き、英語アルファベットの 26 文字を学習します。
- 管理者として `/study/en-library` を開き、モジュールの学習データを確認します。
- `/study/en-classroom` を開き、Study を通じて英語クラスルームのセッションを開始します。
- 有効な Cognis アクセストークンで `/api/v1/modules/study-language-en/library` を呼び出し、利用可能なライブラリレイヤーを読み取ります。
- `study:language:en` Capability を解決し、モジュール内部をインポートせずに言語記述子を連携します。

## 技術仕様

このモジュールは読み取り専用の外部 Cognis 拡張機能です。永続 UUID がリリースをまたいでモジュールを識別し、`requires` エントリが Study ゲートウェイを UUID で宣言します。

### 統合契約

- `bootstrap.js` はプラットフォーム統合に使用する唯一のエントリポイントです。
- 提供される `ctx` は、ルート、UI 登録、Capability、フローフックのための唯一のコンポーネント間バスです。
- ランタイムインポートはリポジトリ相対に限定し、Cognis 内部や他のコンポーネントへ直接アクセスしません。
- スコープ付き登録は、モジュールの無効化またはアンインストール時に削除できます。

### セキュリティ

- ライブラリエンドポイントは、データを読み取る前にリクエストを認証します。
- レイヤー名は許可リストで制限され、データセットのパスはモジュールストア内で固定されています。
- API 応答は実装詳細を公開せず、安定した公開エラーを返します。
- 初期化失敗は、安全な構造化メタデータとともにホストロガーへ送信されます。

### リリース手順

- `manifest.json`、`package.json`、`package-lock.json` のバージョンを同期し、モジュール UUID は決して変更しません。
- リリースをコミットする前に、`npm install`、`npm test`、`npm run lint`、`npm run manifest:hashes`、`npm run check:manifest`、`git diff --check` を実行します。
- 最後の配布ファイル変更後に `manifest.files` を再生成し、すべてのリポジトリ相対パスと SHA-256 ダイジェストを検証可能な状態に保ちます。
