# Cognis English モジュール

Cognis English モジュールは、バージョン付きの宣言型データ専用コンテンツパックとして、インストール可能な英語学習環境を Cognis Study ゲートウェイに提供します。

## 使用例

- `/study/library` を開き、スキーマ駆動の共有 Study ライブラリで英語コンテンツを学習します。
- ホスト提供の `study:library` capability を解決し、ローカライズ済みスキーマメタデータとレイヤーの意味的役割を持つ `en` 名前空間のバージョン付きコンテンツパックへアクセスします。
- `study:language:en` capability を解決し、生成される Study サブナビゲーションボタン用の `languageCode: "en"` を含む正規記述子を取得します。

## 技術仕様

このモジュールは読み取り専用の外部 Cognis 拡張機能です。永続 UUID がリリースをまたいでモジュールを識別し、`requires` エントリが Study ゲートウェイを UUID で宣言します。

### 統合契約

- `bootstrap.js` はプラットフォーム統合に使用する唯一のエントリポイントです。
- 提供される `ctx` は、Capability、フロー、言語リソースの登録に使用する唯一のコンポーネント間バスです。
- ランタイムインポートはリポジトリ相対に限定し、Cognis 内部や他のコンポーネントへ直接アクセスしません。
- スコープ付き登録は、モジュールの無効化またはアンインストール時に削除できます。

- アンインストールフックはライフサイクルのクリーンアップを記録します。学習データセットは読み取り専用のパッケージファイルであるため、このモジュールには保存された設定やユーザー所有のコンテンツはありません。

### セキュリティ

- ホストライブラリは、アトミックな書き込み前にパッケージ名前空間、セマンティックバージョン、ライセンス、安全なパス、ローカライズ済みスキーマ、型付きフィールド、レコードグラフ全体を検証します。
- 取り込み失敗は、安全な構造化メタデータとともにホストロガーへ送信されます。

### リリース手順

- `manifest.json`、`package.json`、`package-lock.json` のバージョンを同期し、モジュール UUID は決して変更しません。
- リリースをコミットする前に、`npm install`、`npm test`、`npm run lint`、`npm run manifest:hashes`、`npm run check:manifest`、`git diff --check` を実行します。
- 最後の配布ファイル変更後に `manifest.files` を再生成し、すべてのリポジトリ相対パスと SHA-256 ダイジェストを検証可能な状態に保ちます。
