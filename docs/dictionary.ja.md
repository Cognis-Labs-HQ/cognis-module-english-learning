# 英語辞書

英語モジュールは `study:library:provider` を通じて無料辞書を登録し、検索画面とキャッシュは Cognis が管理します。

## 使用例

Study の検索欄または語彙フォームで英単語を検索します。同じ構成の読みと意味は Cognis が統合します。API は単語の完全一致検索であり、曖昧な全文候補や文全体の翻訳は提供しません。

## 技術仕様

対象はスキーマ `english`、言語 `en`、レイヤー `words` のみです。エンドポイントは `https://api.dictionaryapi.dev/api/v2/entries/en/`。入力は百文字以内の英字と内部の空白、アポストロフィ、ハイフンに限定します。十五秒でタイムアウトし、転送を拒否します。百万文字を超える JSON や不正レコードは安全なエラーにします。

取得順を保ち、空の意味・重複を除き、定義は最大十件です。IPA も重複を除いて十件に制限します。活用の発音規則を維持するため、収録済みの主要 IPA を先頭にします。品詞タグは既知の活用群を保持しますが、未知の動詞の活用は作りません。文字だけの完全な綴りは同梱アルファベットの ID に解決します。

404 は実際の収録一致または空の結果を返します。通信・サーバー・解析の失敗は安全に記録して Cognis に返します。内容索引の失敗は再試行可能です。モジュールは検索結果のキャッシュや定期実行を持たず、一時間後の確認、十二時間後の変更公開、永続化は Cognis が処理します。

外部定義は英語のままで、翻訳はホストが提供できます。非表示の `dictionary_data` は生の全応答ではなく、エンドポイント、ライセンス、許可された Wiktionary 出典を保持します。結果には CC BY-SA 3.0 と Wiktionary の出典義務がある場合があり、再利用時も遵守します。同一綴りに複数品詞が含まれますが、正式な活用一覧は提供されません。

## 保存される学習設定

同梱の参照資料名は Open English WordNet です。同梱の名詞32語の複数形には専用音声があります。選択した形の表記と優先発音で録音を解決し、録音がない形を基本形の音声で置き換えません。
