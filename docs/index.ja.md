# 英語学習

英語学習 は、版管理された学習グラフ、英語辞書による補完、独自の活字体ガイド、初期デッキを提供します。学習画面と利用者データは Cognis が管理します。

## 同梱学習コンテンツ

書字ガイド、テーマ別の語彙、参照付きの例文、イラスト、初期デッキを提供します。収録内容とメディアのインベントリを、利用可能な項目の参照元とします。

## 使用例

- `/study/en/alphabet`、`/study/en/letter-combinations`、`/study/en/vocabulary`、`/study/en/sentences` から学習内容を参照します。
- Study ナビゲーションの無料辞書で検索すると、選択した語彙がホストのカード編集フォームに反映されます。
- `/study/flashcards` には英語のアルファベット、はじめての英単語、日常の英語動詞、はじめての英文があります。学習、お気に入り、共有は Cognis が処理します。

## 技術仕様

### 提供契約とライフサイクル

固定モジュール UUID は `b1adc29f-9d54-5785-9bea-2ce76f1981e4`、必要な Study ゲートウェイ UUID は `338b9237-a2c8-5bcf-9437-bccc9abd9a27` です。初期化は `ctx.capabilities.require("study:library:provider")` と、動作する `ingestContentPack`、`registerLookupProvider`、`deleteContentPack` を要求します。書字・辞書プロバイダーを登録し、`data/library/` を取り込み、その後 `study:language:en` と解除可能な `bootstrap-platform` フローへの参加を公開します。記述子には `code`、`languageCode`、モジュール版、パッケージ、`starterDecks` が含まれます。

管理者専用の GET・PUT・DELETE 設定ルートは有効なモジュールの起動時だけ登録します。無効状態の実行エントリーポイントはありません。音声設定は無効化と再起動後も保持し、学習内容の保持とは独立してアンインストール時に削除します。

### コンテンツグラフ

コンテンツパックは、小文字と大文字、綴りの組み合わせ、語彙、文構造、翻訳済み定義を提供します。定義はホストの `studyenglish:definitions` プレフィックスを、マーケットプレイスの文字列は `module.study.language.en.*` を使用します。モジュールとコンテンツのメタデータは各マニフェストに記載されています。

綴りと文の順序付き参照は実際のレコードに解決します。非表示の活用形は収録文の検証に必要な文字通りの参照先であり、対話式フォームには動詞・コピュラ・形容詞の宣言的な活用群を用意しています。不規則形と IPA も含みます。IPA は音声表記なので、無関係なアルファベット文字に接続しません。大文字文頭は元の文を保持します。否定、前置詞、接続詞、句読点の文法カードは編集できません。定義の関連付けは最大十件です。

フォーム契約は書字項目、語彙の文字カルーセル、文の単語・小辞カルーセル、文構造カルーセルを宣言します。検証、UUID 解決、空白、インポート、上限、通知はホストが担当します。アルファベット表は七列で、大文字を小文字の子として表示します。最小プレビューは原子的な文字のみです。

### 書字ガイドとメディア

各文字と組み合わせには、筆順、時刻、文字ごとのグループを持つ独自の正規化 JSON 活字体ガイドがあります。プロバイダーは同梱データの複製を返し、遠隔取得しません。入門用ガイドであり、唯一の手書き様式を指定するものではありません。

### 辞書の責任範囲

無料辞書は `https://api.dictionaryapi.dev/api/v2/entries/en/<word>` から英語の語彙のみを検索します。版管理され、対象項目と検索機能を宣言しますが、文の翻訳や書字ガイドは提供しません。入力と応答を制限・検証し、固定エンドポイントのみを使い、転送を拒否し、15 秒でタイムアウトします。取得順を保持して読み・意味の重複を除き、定義と読みは最大十件です。出典・ライセンス情報は非表示の `dictionary_data` に保持します。外部の意味は英語のままとし、他言語はホストの翻訳機能が補完します。詳細は辞書ドキュメントを参照してください。

収録語は検証済みの主要 IPA と活用タグを保持します。文字だけの新しい綴りは収録アルファベットに接続し、未知の動詞の不規則活用は推測しません。404 では実際の収録一致を返し、失敗・不正応答は安全なエラーにします。永続キャッシュ、一時間後の確認、十二時間後の変更公開は Cognis core が管理します。モジュールは不変の内容索引だけを保持し、辞書応答キャッシュやタイマーを持ちません。

### 配布と検証

特権はホストの言語名前空間への公開に必要であり、Study の権限を迂回しません。実行時のインポートはリポジトリ内に限定し、テストでは公開契約のローカル代替を使います。四言語のリソースとドキュメントを配布します。独自の内容・ガイドは AGPL-3.0-or-later、外部辞書の出典は別に保持します。

`npm install`、`npm run manifest:hashes`、`npm test`、`npm run lint`、`npm run check:manifest`、`git diff --check` を実行します。最終の配布ファイル変更後にハッシュを再生成します。変更履歴はパッケージに含めません。

## 初期デッキの拡充

英語は、アルファベット、大文字、文字の組み合わせ、語彙、動詞、形容詞、文、身近なもの、食べ物、体の部位を扱う翻訳済み初期デッキを提供します。固定キーと完全なアルファベット順を `data/starter-decks.json` と照合して検証します。

スキーマは形容詞フィルターを一つ提供し、コンテンツの識別子を維持します。ctxはアプリケーションの基盤であり、Cognisが操作フロー、ユーザーデータ、辞書キャッシュを管理します。

## 共通の言語ページ

内容プロバイダーに子ページがなくても、言語選択は Cognis の探索ページを開きます。言語を切り替えると同じ書字・語彙・文の役割を保ち、フラッシュカード・ライブラリ・申請では共通のページを維持します。英語はアルファベット・文字の組み合わせ・語彙・文を独自のパス名で宣言します。中断したお気に入り読み込みはマウントを終了し、誤解を招く失敗通知を表示しません。

## アルファベット・文法・名詞の数

アルファベットは文字名と任意の `letter_sounds` IPA情報を区別し、埋め草のセルを含みません。句読点は専用の文作成カルーセルに表示します。節と談話の構造には翻訳済みの意味と発音があります。確認済みの可算名詞は `flag: "transform:plural"` でCognisの複数形変換を有効にし、綴りや発音の変化にも対応します。不可算名詞は対象外で、派生形は重複したレコードではなく基本カードから生成します。

### 開発者向け構成とホストの責任範囲

新しいモジュールは[cognis-module-template](https://github.com/Cognis-Labs-HQ/cognis-module-template)から作成し、このリポジトリでは`AGENTS.md`に記載されたテンプレート版の指針に従います。`bootstrap.js`はライフサイクルの調整、`api/index.js`はctx依存関係の接続、`api/routes/<domain>/index.js`はHTTP処理、`api/reuse/`は再利用するサーバーコードを担当します。ブラウザー機能は`ui/`、スタイルは`ui/styles/`、再利用するマークアップは`ui/templates/`、翻訳された文書は`docs/index.<locale>.md`に配置します。過去のリリース記録は`docs/changelog/`に置き、パッケージのハッシュ対象から除外します。対応しない任意の領域は作成しません。

公開ctx機能と宣言されたフローを利用し、Cognis内部や他のモジュールをインポートしないでください。ダッシュボードの機能・ナビゲーション提供スクリプトは`mountProvider(scopedUiCtx)`を公開し、所有するリソースの終了処理を返します。インポート時にモジュールの動作を登録してはいけません。ホストは無効化時に機能、フローフック、リスナー、提供状態を解除し、再有効化時にキャッシュ済みスクリプトを再マウントします。設定・管理画面のファクトリーと認証フッターの記述子は、それぞれの公開ホスト契約に従います。独立したテスト用実装で契約を検証し、構成チェックを実行し、最後のパッケージ変更後にハッシュを更新して、公開前にlint、テスト、マニフェスト検証を実行してください。

パッケージ検証では、エントリーポイント、アイコン、バナー、スクリーンショットが、解決済みのパスを含めチェックアウト内の通常ファイルであることを確認します。ドキュメントは公開契約を説明し、リリースのメタデータにはマニフェストを参照します。変更履歴にはリリースの来歴を保持します。

文カードは Library スキーマを通じて最低2つの単語参照を必要とします。初級のあいさつを「Hello, my friend!」に変更し、対応する構成リンクと各言語の定義を用意します。正確な IPA を発音形式として維持し、ホストの Library が読みやすい書体で記号を表示します。

## Studyモジュールの構成

管理者専用の GET・PUT・DELETE 設定ルートは有効なモジュールの起動時だけ登録します。無効状態の実行エントリーポイントはありません。音声設定は無効化と再起動後も保持し、学習内容の保持とは独立してアンインストール時に削除します。

## 品詞と複数形の正確さを保つ

Free Dictionaryは品詞ごとに候補を分け、対応する定義、タグ、監修済み活用だけを含めます。現在のアルファベットグラフで表現できないため、アポストロフィーやハイフンを含む検索語は受け付けません。応答はストリーム読み込み中に百万バイトへ制限し、超過時は即座に中止します。公開済みフロー識別子`study-language-en:bootstrap-registration`は維持します。複数形への変換は単数形`book`だけに適用し、すでに複数の`books`には適用しません。`houses`は`/haʊzɪz/`を使います。翻訳済み初期デッキを文書化します。

## 音声と録音

同梱WAVはチェックサム・形式・PCMの整合性を確認します。聴取による検証は別に記録し、未検証の場合もあります。`data/audio/recordings.json` は利用可能な録音と結合音声を、`data/audio/unavailable.json` は音声未収録のカードを明示します。未収録の音声に再生URLは設定しません。指定音声は `gJx1vCzNCD1EQHT212Ls` です。認証情報やオフライン生成ツールは同梱しません。

文には、選択された活用形を含む構成単語・助詞の録音を順番に並べ、そのPCMサンプルをそのまま使用します。このため、同梱文の声と発音は単語の個別再生と一致します。新しい文にはホストの結合処理を使用し、派生形の録音がない場合に基本形の発音で代用しません。対象は厳選パックであり、必要時に読み込む辞書の全項目や任意のユーザー作成文ではありません。

起動時に解除可能な `study:audio:provider.registerProvider` を登録します。同梱カードと派生形はElevenLabsの導入・設定なしで利用できます。未収録の語彙は任意依存の設定済み `elevenlabs-tts:synthesis` を利用できます。要求の既定音声は言語の指定音声で、管理者は新規合成用の音声を変更できます。新しい文を文全体として別途合成しません。Cognisがグローバルカードの権限、キャッシュ、手動アップロード、個人・クラス用の結合方針を管理します。最初に記載された発音のみ選択します。

生成ファイルは24 kHz、モノラル、16ビットPCMで、ピーク制限と無音でないことを検証します。要求は言語別の固定モデル、速度0.9、類似度0.85、スタイル0を使用し、安定度は英語0.75、日本語0.9です。シードは要求ごとに保持し、無音として拒否した出力は声を変更せず再生成します。英語では記載されたIPA音素タグを使用します。コンテンツマニフェストに同梱アセットディレクトリを宣言し、インストール用のパック版を更新します。

各レイヤーはホストのカード編集・詳細画面に参考画像フィールドを提供します。語彙には OpenAI の画像生成で作成した独自の色鉛筆・水彩調のイラストを使用し、第三者の写真は同梱しません。`data/library/assets/images/catalog.json` に生成元、切り出し情報、カードとの対応、チェックサムを記録し、`data/library/assets/images/LICENSE.md` に画像ライセンスを記載します。管理者は Cognis から追加の参考画像をアップロードできます。

## 録音インベントリ

`data/audio/recordings.json` はインベントリ形式2を使用し、言語・声・モデル・処理設定・総数・用途別索引のパスとハッシュを保持します。`data/audio/indexes/` は `data/audio/inventories/` の分割ファイルをハッシュ付きで列挙し、文字・語彙・活用・文全体・構成語合成の用途に分けます。主索引と用途別索引は400行未満、録音の分割ファイルは800行以下を維持します。読み込み時に両階層のハッシュ、件数、許可パス、用途と種類の対応、重複パスを検証してから再生を登録します。録音オブジェクト、音声バイト列、検索優先順位を保持します。

同梱文の再生は選択した活用形も含め、構成要素と同一の PCM を連結した録音を使用します。別生成の文全体の録音は音声とリクエストの来歴を保持したまま一覧に残しますが、合成録音を上書きしません。新しい文はホストによる合成とキャッシュを使用します。

## 明示的なカタログ正規化と文の合成録音一覧

同梱文の再生は選択した活用形も含め、構成要素と同一の PCM を連結した録音を使用します。別生成の文全体の録音は音声とリクエストの来歴を保持したまま一覧に残しますが、合成録音を上書きしません。新しい文はホストによる合成とキャッシュを使用します。

## 画像ラベルの翻訳と中立的なファイル名

画像ファイル名と ID は SHA-256 ハッシュを使用し、元シートの識別子も出典のハッシュを使用します。カタログのメタデータはカードに既存の意味からドイツ語・英語・インドネシア語・日本語のラベルを提供します。表示ラベルと中立的な保存識別子を分離しました。画像データとカード ID は維持し、コンテンツ改訂ですべての画像参照を更新します。

## 最終レビューと無効な言語へのアクセス

アンインストールでは学習内容を保持する場合も音声設定を削除します。無効化するとモジュールのルート、静的 UI、プロバイダー登録を解除します。設定は無効化と再起動をまたいで保持し、有効な間だけ提供します。Cognis は稼働中の言語プロバイダーに基づいて保存済みスキーマ・カード・メディアへのアクセスを制限し、再有効化で復元します。参照検索は同一の出典識別子を統合し、元レコード、読み順、意味を保持します。同梱文は構成要素と同一の PCM 合成録音を優先し、直接録音も別途保持します。音声生成前に正規化済みの文字種と長さを検証します。KanjiVG の失敗応答は破棄し、長音符にも対応します。

## 動的に生成される活用形

各活用セットは文法上の `matchTags` と必須の `flag`（例：`transform:verb`、`transform:plural`）を宣言します。対応するフラグを持つ基本カードだけが活用を有効にします。不明または生成不能なフラグは検証に失敗します。活用形は基本カードの正規UUIDと `{setId, path}` で識別する読み取り専用ビューです。独立したカードとして作成、インポート、同梱することはできません。文法クラスの異なる独立した同形語は保持できます。

詳細表示、文の検証、音声は同じ解決処理を使います。生成ビューは参考画像を保持し、基本形の音声・筆順フィールドを除去します。生成した表記と第一発音で音声を検索し、再生成しても基本カードを変更しません。書字練習は生成した表記の文字パターンを合成し、筆画グループを保持して空白を無視します。録音テストでは有効な各規則に経路付きのクリップを必須とします。活用形カードの保存表現や互換用の別名はサポートしません。

公開プロバイダー契約は `transformationModel: "generated"` を宣言し、両言語モジュールは登録前にこれを必須とします。有効なセットの各規則が基本カードに適用できなければ検証に失敗します。形容詞から副詞への変換など、品詞が変わる規則は `resultClass` を指定できます。明示的な参照が無効な場合は基本形に置き換えず、処理を拒否します。

## オフライン学習

Study は現在のタブ内に容量制限付きの軽量 JSON スナップショットを保持します。対象はスキーマ、許可された文字・カードデータ、保存先、閲覧済み ID、お気に入り、以前開いたデッキです。言語スキーマは `metadata.offline: { cache: "lightweight" }` で対応を宣言します。Library キャッシュは最大 16 MB・100 件、その他の読み取りキャッシュは最大 4 MB・100 件です。音声バイト、辞書応答、認証情報、認証済み文書は永続保存しません。

Explore のプレビューは認可済みのキャッシュ行から関係を解決します。描画は新しいガイドでローカル動作し、フラッシュカード練習もローカルで進められます。音声、辞書、ElevenLabs への要求は停止し、オフライン練習では進捗、XP、報酬、お気に入り、編集を保存しません。以前読み込んだ、容量制限内のコンテンツだけが利用でき、不足する依存データは利用できません。

非公開の Study では、同じタブ内で以前検証済みの、有効期限内の同じアカウントセッションが必要です。再読み込みと初回訪問では引き続き公開ページ専用のオフライン契約が適用されます。アカウント・セッション、設定、モジュールの状態が変わるか、プロバイダーが破棄されると非公開スナップショットを無効化します。切断中はサーバーでのアクセス取り消しを検知できません。復旧時には未保存変更を確認してから再読み込みし、サーバーの認可を更新します。
