# 英語学習

英語学習 は、版管理された学習グラフ、英語辞書による補完、独自の活字体ガイド、七つの初期デッキを提供します。学習画面と利用者データは Cognis が管理します。

## 使用例

- `/study/en/alphabet`、`/study/en/letter-combinations`、`/study/en/vocabulary`、`/study/en/sentences` から学習内容を参照します。
- Study ナビゲーションの無料辞書で検索すると、選択した語彙がホストのカード編集フォームに反映されます。
- `/study/flashcards` には英語のアルファベット、はじめての英単語、日常の英語動詞、はじめての英文があります。学習、お気に入り、共有は Cognis が処理します。

## 技術仕様

### 提供契約とライフサイクル

固定モジュール UUID は `b1adc29f-9d54-5785-9bea-2ce76f1981e4`、必要な Study ゲートウェイ UUID は `338b9237-a2c8-5bcf-9437-bccc9abd9a27` です。初期化は `ctx.capabilities.require("study:library:provider")` と、動作する `ingestContentPack`、`registerLookupProvider`、`deleteContentPack` を要求します。書字・辞書プロバイダーを登録し、`data/` を取り込み、その後 `study:language:en` と解除可能な `bootstrap-platform` フローへの参加を公開します。記述子には `code`、`languageCode`、モジュール版、パッケージ、`starterDecks` が含まれます。

無効化や初期化失敗時には検索プロバイダーを解除します。ルート、静的ディレクトリ、ケイパビリティ、フックはホストのモジュールスコープで管理します。管理者専用の `DELETE /api/v1/modules/study-language-en/config` は 204 を返し、無効時も利用できます。保存設定はありません。アンインストールで `deleteContent: false` は内容を保持し、`true` はライフサイクル中も利用できる提供契約の `deleteContentPack` を呼び出します。トランザクションによる連鎖削除と通知は Cognis が担当します。失敗は安全な構造化ログとともに伝播します。

### コンテンツグラフ

コンテンツパックは、小文字と大文字、綴りの組み合わせ、語彙、文構造、翻訳済み定義を提供します。定義はホストの `studyenglish:definitions` プレフィックスを、マーケットプレイスの文字列は `module.study.language.en.*` を使用します。モジュールとコンテンツのメタデータは各マニフェストに記載されています。

綴りと文の順序付き参照は実際のレコードに解決します。非表示の活用形は収録文の検証に必要な文字通りの参照先であり、対話式フォームには動詞・コピュラ・形容詞の宣言的な活用群 37 個を用意しています。不規則形と IPA も含みます。IPA は音声表記なので、無関係なアルファベット文字に接続しません。大文字文頭は元の文を保持します。否定、前置詞、接続詞、句読点の文法カードは編集できません。定義の関連付けは最大十件です。

フォーム契約は書字項目、語彙の文字カルーセル、文の単語・小辞カルーセル、文構造カルーセルを宣言します。検証、UUID 解決、空白、インポート、上限、通知はホストが担当します。アルファベット表は七列で、大文字を小文字の子として表示します。最小プレビューは原子的な文字のみです。

### 書字ガイドとメディア

各文字と組み合わせには、筆順、時刻、文字ごとのグループを持つ独自の正規化 JSON 活字体ガイドがあります。プロバイダーは同梱データの複製を返し、遠隔取得しません。入門用ガイドであり、唯一の手書き様式を指定するものではありません。同梱音声ファイルについては後述します。外部 TTS URL はパッケージアセットではありません。

### 辞書の責任範囲

無料辞書は `https://api.dictionaryapi.dev/api/v2/entries/en/<word>` から英語の語彙のみを検索します。版管理され、対象項目と検索機能を宣言しますが、文の翻訳や書字ガイドは提供しません。入力と応答を制限・検証し、固定エンドポイントのみを使い、転送を拒否し、15 秒でタイムアウトします。取得順を保持して読み・意味の重複を除き、定義と読みは最大十件です。出典・ライセンス情報は非表示の `dictionary_data` に保持します。外部の意味は英語のままとし、他言語はホストの翻訳機能が補完します。詳細は辞書ドキュメントを参照してください。

収録語は検証済みの主要 IPA と活用タグを保持します。文字だけの新しい綴りは収録アルファベットに接続し、未知の動詞の不規則活用は推測しません。404 では実際の収録一致を返し、失敗・不正応答は安全なエラーにします。永続キャッシュ、一時間後の確認、十二時間後の変更公開は Cognis core が管理します。モジュールは不変の内容索引だけを保持し、辞書応答キャッシュやタイマーを持ちません。

### 配布と検証

特権はホストの言語名前空間への公開に必要であり、Study の権限を迂回しません。実行時のインポートはリポジトリ内に限定し、テストでは公開契約のローカル代替を使います。四言語のリソースとドキュメントを配布します。独自の内容・ガイドは AGPL-3.0-or-later、外部辞書の出典は別に保持します。

`npm install`、`npm run manifest:hashes`、`npm test`、`npm run lint`、`npm run check:manifest`、`git diff --check` を実行します。最終の配布ファイル変更後にハッシュを再生成します。変更履歴はパッケージに含めません。

## 初期デッキの拡充

英語は七つの初期デッキを提供します。既存の四つに、大文字、綴りの組み合わせ、日常形容詞を追加します。固定キー、各言語の名称、完全なアルファベット順を検証します。

スキーマは形容詞フィルターを一つ提供し、コンテンツの識別子を維持します。ctxはアプリケーションの基盤であり、Cognisが操作フロー、ユーザーデータ、辞書キャッシュを管理します。

## 共通の言語ページ

内容プロバイダーに子ページがなくても、言語選択は Cognis の探索ページを開きます。言語を切り替えると同じ書字・語彙・文の役割を保ち、フラッシュカード・ライブラリ・申請では共通のページを維持します。英語はアルファベット・文字の組み合わせ・語彙・文を独自のパス名で宣言します。中断したお気に入り読み込みはマウントを終了し、誤解を招く失敗通知を表示しません。

## アルファベット・文法・名詞の数

アルファベットは文字名と任意の `letter_sounds` IPA情報を区別し、埋め草のセルを含みません。句読点は専用の文作成カルーセルに表示します。節と談話の構造には翻訳済みの意味と発音があります。確認済みの可算名詞は `optInTag: plural` でCognisの複数形変換を有効にし、綴りや発音の変化にも対応します。不可算名詞は対象外で、派生形は重複したレコードではなく基本カードから生成します。

### 開発者向け構成とホストの責任範囲

新しいモジュールは[cognis-module-template](https://github.com/Cognis-Labs-HQ/cognis-module-template)から作成し、このリポジトリでは`AGENTS.md`に記載されたテンプレート版の指針に従います。`bootstrap.js`はライフサイクルの調整、`api/index.js`はctx依存関係の接続、`api/routes/<domain>/index.js`はHTTP処理、`api/reuse/`は再利用するサーバーコードを担当します。ブラウザー機能は`ui/`、スタイルは`ui/styles/`、再利用するマークアップは`ui/templates/`、翻訳された文書は`docs/index.<locale>.md`に配置します。過去のリリース記録は`docs/changelog/`に置き、パッケージのハッシュ対象から除外します。対応しない任意の領域は作成しません。

公開ctx機能と宣言されたフローを利用し、Cognis内部や他のモジュールをインポートしないでください。ダッシュボードの機能・ナビゲーション提供スクリプトは`mountProvider(scopedUiCtx)`を公開し、所有するリソースの終了処理を返します。インポート時にモジュールの動作を登録してはいけません。ホストは無効化時に機能、フローフック、リスナー、提供状態を解除し、再有効化時にキャッシュ済みスクリプトを再マウントします。設定・管理画面のファクトリーと認証フッターの記述子は、それぞれの公開ホスト契約に従います。独立したテスト用実装で契約を検証し、構成チェックを実行し、最後のパッケージ変更後にハッシュを更新して、公開前にlint、テスト、マニフェスト検証を実行してください。

パッケージ検証では、エントリーポイント、アイコン、バナー、スクリーンショットが、解決済みのパスを含めチェックアウト内の通常ファイルであることを確認します。ドキュメントは公開契約を説明し、リリースのメタデータにはマニフェストを参照します。変更履歴にはリリースの来歴を保持します。

文カードは Library スキーマを通じて最低2つの単語参照を必要とします。初級のあいさつを「Hello, my friend!」に変更し、対応する構成リンクと各言語の定義を用意します。正確な IPA を発音形式として維持し、ホストの Library が読みやすい書体で記号を表示します。

## Studyモジュールの構成

コンテンツパックは`data/library/`に配置し、マニフェスト、スキーマ、コンテンツファイルを一つの取り込み・削除境界として扱います。初期デッキは`data/starter-decks.json`に残します。実行時プロバイダーは`api/dictionary/`と`api/strokes/`、決定的なファイル読み込みとバイト数を制限した応答デコードは`api/reuse/`に配置します。横断的なコンテンツ・ライフサイクルテストは`tests/`、プロバイダー・通信・APIテストは`api/tests/`に置きます。マニフェストは`api/routes/config/index.js`を`disabledApi`として宣言し、この入口では管理者限定の設定DELETEルートだけを登録します。コンテンツの取り込みやプロバイダーの起動は行いません。公開済みフロー識別子は維持します。

## 品詞と複数形の正確さを保つ

Free Dictionaryは品詞ごとに候補を分け、対応する定義、タグ、監修済み活用だけを含めます。現在のアルファベットグラフで表現できないため、アポストロフィーやハイフンを含む検索語は受け付けません。応答はストリーム読み込み中に百万バイトへ制限し、超過時は即座に中止します。公開済みフロー識別子`study-language-en:bootstrap-registration`は維持します。複数形への変換は単数形`book`だけに適用し、すでに複数の`books`には適用しません。`houses`は`/haʊzɪz/`を使います。七つの翻訳済み初期デッキを文書化します。

## 発音音声

初期録音は ElevenLabs API で生成し、英語には `ELEVENLABS_EN_VOICE_ID`、日本語には `ELEVENLABS_JA_VOICE_ID` を使用します。遅めの発話、128 kbps、開始前の無音 200 ms、終了後の無音 180 ms、上限付きピーク正規化を適用します。一覧にモデルと処理設定を記録し、`data/audio/VOICE-LICENSE.txt` に適用される ElevenLabs の利用条件を示します。

`node scripts/generate-audio.mjs` で一覧を再生成します。Python、FFmpeg、`ELEVENLABS_API_KEY` と対象言語の声の環境変数を用意し、`python3 scripts/synthesize-audio.py --cache <非公開キャッシュディレクトリ>` を実行します。再開時はキャッシュ内の API 応答を再利用します。認証情報や声の識別子はパッケージに保存しません。生成は開発用ツールであり、再生に ElevenLabs の認証情報は不要です。

## 音声プロバイダー契約

Bootstrap は `study:audio:provider` を必須とし、辞書と筆順のプロバイダーとともに解除可能な音声プロバイダーを登録します。発話ラベルと優先する読みに基づいて同梱録音を解決し、容量制限付きでファイルを読み、不足する音声は明示的なエラーにします。解除時には処理中の取得を中断します。Cognis はカードへのアクセスを認可し、スキーマから選択した変形の発話形を導出し、作成済みフィールドを変更せず Files に非公開キャッシュを保存します。`study:library:audio` フローは認可、検証、解決を実行し、`study:audio:fetch` はプロバイダーのバイト列を検証して取得します。文の音声は構成要素を順番に再生します。

音声の取得は学習者が再生を要求したときに始まり、カードを開くだけでは音声を要求しません。再生エラーはホストのローカライズ済みトーストと構造化ログで示します。文の構成要素は選択した変形記述を保持し、認証済み音声エンドポイントは任意の表示テキストを受け取らず、スキーマから発話形を導出します。英語の文字組み合わせの初期音声は記載された IPA 音素から合成し、アルファベットの音声は文字名を発音します。

## 辞書音声とホストのキャッシュ

要求された発音が同梱されていない場合、English Study は English Dictionary API で単語を検索し、その発音メディアエンドポイントから一致する MP3 を取得します。優先 IPA の読みが指定されている場合は一致が必須で、異なる発音で代用しません。`api.dictionaryapi.dev` の HTTPS メディアだけを許可し、リダイレクトを拒否します。検索とダウンロードは一つの制限時間を共有し、両方の応答をストリーミング時のバイト数で制限します。録音がない場合は明示的なエラーを返します。Google の音声サービスは使用しません。

録音キャッシュはモジュールではなく Cognis が管理します。認可後、非公開の Files キャッシュで取得済み録音をカード間および再起動後も再利用します。同時再生要求は取得と保存を共有します。キーには提供元の識別子、リビジョン、言語、役割、ラベル、読みを含め、読みや提供元リビジョンが変われば別途解決します。要求や保存の失敗は再試行できます。モジュールが辞書に接続するのは、再生要求時にキャッシュがない場合だけです。

## 間を付けた合成と手動置換

文カードには任意の音声フィールドがあります。初回再生時に Cognis は全構成要素へのアクセスを認可し、最初の発音グループだけを選び、指定の変形を適用して、開始前の無音と単語・読点・文末の間を持つ一つの連続 WAV を生成します。録音は非公開でキャッシュし、構成音声のバイト列、読み、変形、間の変更で識別子が変わります。新規カードと既存カードの両方で必要時に生成します。通常の作成画面で音声をアップロードすると生成音声を即座に置き換え、明示ファイルを削除すると自動合成に戻ります。提供元は語の録音を提供し、Cognis が合成とキャッシュ方針を管理します。

## 参照データの収録範囲

日本語の参照カタログは同梱する公式 KANJIDIC2 データの全 13,108 字、英語のカタログは Open English WordNet の全 135,969 語彙項目（正規化キー 127,311 件）を収録します。別の遅延読込辞書プロバイダーであり、149,077 件のカードを起動時に一括取り込みするものではありません。Study 検索で参照辞書を選び、対応項目を通常のグラフ検証経由で取り込みます。意味や使用可能な読みがない項目は不明のままとし、発音・翻訳・筆順を捏造しません。全 Unicode 漢字や存在し得る全英単語の網羅を意味しません。

漢字の読みは JMdict の一般的な用例と利用可能な頻度情報に基づき、送り仮名形も含めて並べます。グループ参照と初期音声は同じ順序に従い、漢字再生は常に最初の読みを使います。既存英単語カードには一つの IPA を収録し、参照項目は優先する英国発音内の原資料の順序を他の方言より先に維持します。発音頻度は文脈に依存し、原資料は全ての読みの普遍的順位を提供しません。

`python3 scripts/import-reference.py --source <source-file>` で参照シャードを再生成します。日本語は `--priorities <reading-priorities.json>` に対応します。`data/reference/manifest.json` に原資料のチェックサム、帰属、件数、シャードのハッシュを記録します。要求されたキーのシャードだけを読み込み、実行時の検索結果は Cognis がキャッシュします。

## 参照項目の完全な読みの録音

日本語はさらに `data/audio/reference/` の容量制限付きバンクに、完全な読みのニューラル音声 2,913 件を同梱します。初期録音と合わせて、原資料で読みが分かる全 12,356 字の優先読みに対応します。残る 752 字には読みが記録されておらず、音声を捏造しません。索引は最初の読みを選び、ファイル範囲と中断を確認します。`python3 scripts/reference-audio.py plan --work <directory>` で計画を作り、合成スクリプトで一覧を処理し、`pack` で容量制限付きバンクを生成します。

日本語の並べ替えツールは `--dictionary <JMdict.gz> --kanji-dictionary <KANJIDIC2.xml.gz> --output <priorities.json>` と任意の `--content-root data/library/content` に対応します。一般的な独立語の読みを優先し、他の読みは実在語の対応付けを頻度で重み付けして並べ、`data/audio/primary-readings.json` の確認済み単字カード用の指定を維持します。連濁と促音化は原資料の標準読みに戻して集計します。訓・音・名乗りの読みを保持し、選択された最初の読みだけが再生とキャッシュ識別を決めます。頻度情報は順序付けの手掛かりであり、全発音に通用する普遍的な頻度測定ではありません。

自動合成には発話対象の構成要素の録音が必要です。不足する録音は明示的なエラーとし、通常の音声アップロード欄から補えます。同梱アルファベットに結び付けられない参照項目の綴りは、原文と定義を保持し、架空の綴りリンクを作りません。
