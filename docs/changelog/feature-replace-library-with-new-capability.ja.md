# 英語学習の更新

**機能ブランチ:** feature-replace-library-with-new-capability

## Capability ベースの学習データ

宣言型の英語コンテンツパックを、ホスト提供の `study:library` capability 経由でアトミックに導入します。重複していたライブラリ API、ストア、ページ、ナビゲーション項目は削除し、スキーマ駆動のホスト表示に統一しました。

## イングランド国旗のアートワーク

モジュールアイコンを、汎用の Cognis 文字マークから拡大縮小可能なイングランド国旗の SVG に変更しました。

## 選択言語の維持

言語 capability は、正規の Study 言語記述子として `languageCode: "en"` を提供します。Cognis PR #215 は生成した Study サブナビゲーションボタンにこのコードを保存し、選択状態をルーター state で渡すため、モジュール URL に言語クエリを付ける必要がなくなりました。

## バージョン付き言語パッケージ契約

英語パックが `en` 名前空間を所有し、ローカライズ済みスキーマメタデータとレイヤーの意味的役割を公開するようにしました。新しい不変のスキーマ・パッケージ版を使い、Cognis PR #214 に従って検証済みパッケージ識別情報を言語 capability から通知します。

## データ専用 Study パッケージ

モジュール固有のアルファベット、クラスルーム、ナビゲーション、CLI、API、スタイルを削除しました。Cognis は、公開された不変のパッケージ記述子、意味的スキーマ、ローカライズ済みメタデータから英語パッケージを汎用的に検出して表示します。静的に登録するのは言語リソースだけです。

## 解決可能な辞書定義

スキーマにライブラリの定義ローカライズ契約と、アルファベットから定義への明示的な必須関係を追加しました。すべての同梱文字は、各モジュール言語バンドルで解決できる文字列キーを持つ定義を参照し、コンテンツレコードにも一致するローカライズ済みテキストを格納します。

## 最新のライブラリスキーマ

このパックは最新の Study ライブラリスキーマに準拠します。アルファベットには発音一覧と外部音声を持たせ、語彙を順序付き綴りと多言語定義に関連付け、文の並びでは語彙語と文法的な助詞を区別します。バイナリメディアは同梱しません。

## 最新ホストとの互換性

スキーマとコンテンツパックをバージョン 14 に更新しました。`minimal: true` を設定するのはアルファベット文字レイヤーだけで、複合文字・定義・単語・助詞・文は意図的に標準カードを維持します。小文字グリッドは安定した数値表示 ID を解決し、大文字の代替項目は異体識別と空間的な親子関係の両方を明示し、単語・助詞・文レイヤーは必須の多言語表示定義を使用します。二重字の構成は定義と分離したままにし、必須メタデータの初期値と安定した識別子によって現在のホスト動作を維持します。

## 分離されたブラウザー領域

モジュールの静的名前空間ではロケールバンドルだけを配信し、グローバルなプラットフォームブートストラップフローへのフックを廃止しました。データ取り込みと公開言語ケイパビリティは維持し、データ専用パッケージがホストのナビゲーションやユーザーメニュー構成へ参加したり干渉したりしないようにします。

## 完全な文の構成

最新の Cognis コンテンツパック検証に合わせ、文ラベル全体を位置が連続する語彙単位と助詞の順序付き参照から解決するようにしました。末尾のピリオドは独自の多言語定義を持つ句読点助詞として格納し、同梱文に未参照の文字列が残らないようにしています。

## 読みやすいアルファベットと発音の拡充

アルファベットを、末尾に明示的な空欄を持つ 7 列 4 行の均整の取れた表として表示するようにしました。大文字・小文字の各レコードに文字名と一般的な IPA 音素を持たせ、既存の二重字に `ph`、`wh`、`ng`、`ck` を追加しました。異体関係では廃止された方向ヒントを使わず、ホストの最新の境界付き動的配置契約に従うため、古い表示データが報告されたライブラリ実行時エラーの一因になることを防ぎます。

## 明示的な空間的子関係

スキーマバージョン 14 では、最新のホスト契約に従って代替形の識別と視覚階層を分離します。大文字から小文字への関係は `variant: true` と `child: true` の両方を宣言し、前者が大文字レコードを代替綴りとして分類し、後者だけが実際の小文字の親の周囲へカードを展開することを許可します。

## ホスト名前空間向けの明示的な特権

Cognis PR #220 は、非特権モジュールの登録を自身のモジュール ID 配下に制限します。この言語モジュールはホスト定義の `study:language:en` ケイパビリティを公開する必要があるため、マニフェストで `privileged: true` を明示するようにしました。要求範囲は明確に限定しており、実行時動作はコンテンツパックの取り込み、言語記述子、モジュール所有ロケールの公開だけです。ホストルートやセキュリティ上重要なフローフックは使用しません。

## 文脈固有の語彙定義

1 文字の単語 `a` により、PR #196 の定義優先順位を示すようにしました。その多言語定義は不定冠詞を説明し、参照元のアルファベットカードが持つ文字定義とは意図的に異なります。語彙上の概念が異なる同梱語彙カードはすべて 4 言語の固有定義を保持します。ホストが参照元定義を使うのは語彙項目に固有の意味がない場合だけで、無関係なナビゲーションではそのフォールバックを破棄します。

## 正式な外部パッケージ契約

スキーマバージョン 14 は Cognis PR #226 の外部パッケージ境界を採用します。コンテンツマニフェストはプロバイダー所有レコードを保護対象として指定し、検証済みの JSON 互換カタログメタデータを保持します。スキーマメタデータも安定したプロバイダー識別情報を公開します。ブートストラップはライフサイクル中に利用できる `study:library` ケイパビリティ を解決し、`inspectContentPack` と `ingestContentPack` の両方を必須として、非更新の検査後にアトミックな取り込みを要求します。すべてのフィールドは引き続き検証済みの組み込み型を使うため、独自検証の例外は不要です。

## 明示的な作成・関係セマンティクス

正式リリース 14.1.0 は、日本語の参照実装と同じパック内移行に従い、スキーマ互換バージョン 14 を同一バージョン内で発展させます。すべてのレコードにプロバイダー中立のコンテンツ分類を付け、定義を非表示、文を複合、助詞を明示的に編集不可としました。実際の綴りと順序付き並びの関係は `composition` を宣言し、定義・異体リンクにはリゾルバーロールを持たせないため、構成タイトルを汚さず逆方向ナビゲーションを統合できます。フィールドスキーマには多言語の作成コントロールと英語範囲の音声ファイル契約を追加しましたが、モジュール所有エディターは有効化していません。

## 有効化時のケイパビリティ可用性

動作している日本語参照実装に合わせ、ライフサイクル中に利用できる `study:library` ケイパビリティを宣言・解決するようにしました。別途公開される `study:library:provider` は外部モジュールの依存関係事前検証時に存在する保証がなく、ブートストラップ実行前に HTTP 409 で有効化が失敗していました。読み取り専用検査とアトミックな取り込みの順序は内部ライブラリサービスで維持されるため、検証動作を変えずに、遅れて公開されるケイパビリティへの有効化依存を解消します。

## ドキュメントと契約

マニフェストは `study:library` を必須とし、現在のホスト所有のアトミック有効化契約に従い、モジュールバージョン 1.2.37 を公開します。

## 変更履歴の構造を標準化

プルリクエストごとにローカライズされた変更履歴を用意する Cognis の規約と、言語の同等性、エントリーの詳細、ブランチ情報、コミット由来を確認する自動テストを追加しました。

リポジトリ固有の Copilot ガイダンスを追加し、モジュール全体のエージェント指示と統一することで、AI 支援のコントリビューションが同じ規則に従うようにしました。

両方の Study モジュールが同じ解除可能な音声プロバイダー契約を使い、制限付きのローカル読み込みで同梱録音を取得します。認可、キャッシュ方針、合成再生はホストが所有します。

## パッケージの参照先と開発者向けガイド

リリース 1.3.8 — パッケージ検証では、エントリーポイント、アイコン、バナー、スクリーンショットが、解決済みのパスを含めチェックアウト内の通常ファイルであることを確認します。ドキュメントは公開契約を説明し、リリースのメタデータにはマニフェストを参照します。変更履歴にはリリースの来歴を保持します。

## 学習グラフの拡張

検証済みの全 635 レコードには、表示語彙 123、文 45、書字ガイド、正確な活用群 37、初期デッキ四つがあります。名前空間と出典 ID を保持し、非表示の活用形と大文字文頭で文の依存関係を明示します。

限定された提供契約を要求し、失敗・無効化時に登録を解除し、アンインストールの削除要求はホストへ委譲します。フロー、キャッシュ、権限、フラッシュカード、共有はホストの責任です。

無料辞書から上限付きの意味と IPA を取得し、出典と文字参照を保持します。独自の JSON ガイドは文字 52 と組み合わせ 17 をカバーし、バイナリアセットは追加しません。不正な同梱 TTS URL を削除し、音声を任意にします。

## 検証と文書

独立した振る舞いテストでライフサイクル、辞書の失敗・上限、グラフ、活用、デッキを検証します。読みやすさの検査で空行を維持します。仕様、辞書ガイド、README、翻訳を四言語で同期します。モジュール 1.3.0 はパッケージ 15.0.0／スキーマ 15 を配布します。

英語は七つの初期デッキを提供します。既存の四つに、大文字、綴りの組み合わせ、日常形容詞を追加します。固定キー、各言語の名称、完全なアルファベット順を検証します。

## 内容と契約の訂正

スキーマ改訂16は重複した形容詞フィルターを削除します。モジュール1.3.1とパッケージ16.0.0は既存のデータ ID を保持します。指示は ctx を基盤とし、操作フロー、利用者データ、辞書キャッシュは Cognis が所有します。

## 共通の言語ページ

内容プロバイダーに子ページがなくても、言語選択は Cognis の探索ページを開きます。言語を切り替えると同じ書字・語彙・文の役割を保ち、フラッシュカード・ライブラリ・申請では共通のページを維持します。英語はアルファベット・文字の組み合わせ・語彙・文を独自のパス名で宣言します。中断したお気に入り読み込みはマウントを終了し、誤解を招く失敗通知を表示しません。

## アルファベット・文法・名詞の数

スキーマ 17 とコンテンツパック 17.0.0 は文字名と任意の IPA 音声情報 `letter_sounds` を分離し、アルファベットの空白埋め合わせセルを除きます。句読点には専用カルーセルを設けます。節・談話の構造を 22 件追加し、翻訳された意味と発音を提供します。確認済みの可算名詞 33 系列は `optInTag: plural` で Cognis の複数形変換を有効にし、綴りと読みの変化も定義します。不可算名詞は対象外です。語形は重複カードを配布せず基本カードから導出します。モジュール版は 1.3.3 です。

## 文を複数の単語で構成

文カードは Library スキーマを通じて最低2つの単語参照を必要とします。初級のあいさつを「Hello, my friend!」に変更し、対応する構成リンクと各言語の定義を用意します。正確な IPA を発音形式として維持し、ホストの Library が読みやすい書体で記号を表示します。

## 文字列の直接指定を禁止し翻訳キーを必須にする

AI向け指示では、すべての経路で英語のユーザー向け文字列の直接指定を禁止します。選択言語に値がない場合は英語のXMLリソースの同じキーを使用できます。英語の代替値も未定義または空の場合は、英語の直接指定、キー名、空の文字列を表示せず、明示的に失敗させます。翻訳の欠落によるエラーを握りつぶしてはいけません。

## 辞書の意味と表記を正しく表現

Free Dictionaryは品詞ごとに候補を分け、対応する定義、タグ、監修済み活用だけを含めます。現在のアルファベットグラフで表現できないため、アポストロフィーやハイフンを含む検索語は受け付けません。

七つの翻訳済み初期デッキを文書化します。

## Studyモジュールの構成

コンテンツパックは`data/library/`に配置し、マニフェスト、スキーマ、コンテンツファイルを一つの取り込み・削除境界として扱います。初期デッキは`data/starter-decks.json`に残します。実行時プロバイダーは`api/dictionary/`と`api/strokes/`、決定的なファイル読み込みとバイト数を制限した応答デコードは`api/reuse/`に配置します。横断的なコンテンツ・ライフサイクルテストは`tests/`、プロバイダー・通信・APIテストは`api/tests/`に置きます。マニフェストは`api/routes/config/index.js`を`disabledApi`として宣言し、この入口では管理者限定の設定DELETEルートだけを登録します。コンテンツの取り込みやプロバイダーの起動は行いません。公開済みフロー識別子は維持します。

## 辞書音声とホストのキャッシュ

要求された発音が同梱されていない場合、English Study は English Dictionary API で単語を検索し、その発音メディアエンドポイントから一致する MP3 を取得します。優先 IPA の読みが指定されている場合は一致が必須で、異なる発音で代用しません。`api.dictionaryapi.dev` の HTTPS メディアだけを許可し、リダイレクトを拒否します。検索とダウンロードは一つの制限時間を共有し、両方の応答をストリーミング時のバイト数で制限します。録音がない場合は明示的なエラーを返します。Google の音声サービスは使用しません。

録音キャッシュはモジュールではなく Cognis が管理します。認可後、非公開の Files キャッシュで取得済み録音をカード間および再起動後も再利用します。同時再生要求は取得と保存を共有します。キーには提供元の識別子、リビジョン、言語、役割、ラベル、読みを含め、読みや提供元リビジョンが変われば別途解決します。要求や保存の失敗は再試行できます。モジュールが辞書に接続するのは、再生要求時にキャッシュがない場合だけです。

## 間を付けた合成と手動置換

初期録音は多言語ニューラルモデル Kokoro をオフラインで使用し、英語に `bf_emma`、日本語に `jf_alpha` を使用します。クリップは 128 kbps、開始前の無音 200 ms、終了後の無音 180 ms、上限付きピーク正規化、遅めの発話速度で生成します。モデルの帰属表示と Apache ライセンスは `data/audio/VOICE-LICENSE.txt`、声と処理設定は録音一覧に記録します。

文カードには任意の音声フィールドがあります。初回再生時に Cognis は全構成要素へのアクセスを認可し、最初の発音グループだけを選び、指定の変形を適用して、開始前の無音と単語・読点・文末の間を持つ一つの連続 WAV を生成します。録音は非公開でキャッシュし、構成音声のバイト列、読み、変形、間の変更で識別子が変わります。新規カードと既存カードの両方で必要時に生成します。通常の作成画面で音声をアップロードすると生成音声を即座に置き換え、明示ファイルを削除すると自動合成に戻ります。提供元は語の録音を提供し、Cognis が合成とキャッシュ方針を管理します。

## 参照データの収録範囲

日本語の参照カタログは同梱する公式 KANJIDIC2 データの全 13,108 字、英語のカタログは Open English WordNet の全 135,969 語彙項目（正規化キー 127,311 件）を収録します。別の遅延読込辞書プロバイダーであり、149,077 件のカードを起動時に一括取り込みするものではありません。Study 検索で参照辞書を選び、対応項目を通常のグラフ検証経由で取り込みます。意味や使用可能な読みがない項目は不明のままとし、発音・翻訳・筆順を捏造しません。全 Unicode 漢字や存在し得る全英単語の網羅を意味しません。

漢字の読みは JMdict の一般的な用例と利用可能な頻度情報に基づき、送り仮名形も含めて並べます。グループ参照と初期音声は同じ順序に従い、漢字再生は常に最初の読みを使います。既存英単語カードには一つの IPA を収録し、参照項目は優先する英国発音内の原資料の順序を他の方言より先に維持します。発音頻度は文脈に依存し、原資料は全ての読みの普遍的順位を提供しません。

## 参照項目の完全な読みの録音

日本語はさらに `data/audio/reference/` の容量制限付きバンクに、完全な読みのニューラル音声 2,913 件を同梱します。初期録音と合わせて、原資料で読みが分かる全 12,356 字の優先読みに対応します。残る 752 字には読みが記録されておらず、音声を捏造しません。索引は最初の読みを選び、ファイル範囲と中断を確認します。`python3 scripts/reference-audio.py plan --work <directory>` で計画を作り、合成スクリプトで一覧を処理し、`pack` で容量制限付きバンクを生成します。

日本語の並べ替えツールは `--dictionary <JMdict.gz> --kanji-dictionary <KANJIDIC2.xml.gz> --output <priorities.json>` と任意の `--content-root data/library/content` に対応します。一般的な独立語の読みを優先し、他の読みは実在語の対応付けを頻度で重み付けして並べ、`data/audio/primary-readings.json` の確認済み単字カード用の指定を維持します。連濁と促音化は原資料の標準読みに戻して集計します。訓・音・名乗りの読みを保持し、選択された最初の読みだけが再生とキャッシュ識別を決めます。頻度情報は順序付けの手掛かりであり、全発音に通用する普遍的な頻度測定ではありません。

## 任意の音声連携

ElevenLabsを任意のモジュール依存関係として宣言します。インストール時に音声合成用として選択できますが、未導入でもStudyの有効化と録音・結合音声を使用できます。

## 特権なしで音声機能を公開

モジュール自身の名前空間で `elevenlabs-tts:synthesis` を公開し、特権フラグを削除します。英語・日本語Studyは既存の任意依存関係を利用し、ctx経由で機能を解決します。Studyの橋渡し処理は呼び出し側から現在の機能を取得する関数を受け取り、無効化・再有効化と設定済み音声に対応します。

## 音声機能を任意に維持

公開機能は `configured` で現在の準備状態を通知します。StudyはAPIキーと既定の声が保存された後にのみ自動音声を有効にします。ElevenLabsが未導入・無効・未設定でも言語登録は成功し、アップロード音声と既存音声の結合を利用できます。合成は要求しません。

## メディアを同梱しないインストールを修正

データ専用コンテンツパックから未使用のアセットディレクトリ宣言を削除し、パックのバージョンを更新します。パッケージ対象のファイルだけで一時インストールを作成し、宣言されたパスを検証することで、空のローカルディレクトリに依存する有効化を防ぎます。

## 一貫した指定音声を同梱

発音を持つすべての厳選カードと、到達可能な複数形・動詞や副詞の派生形に言語ごとの指定音声を同梱します。文のWAVには、選択した活用形を含む構成音声のPCMを順番にそのまま使用します。音声・モデル・要求の出所、チェックサム、無音検証を記録し、認証情報は含めません。

## 保存される学習設定

同梱の参照資料名は Open English WordNet です。同梱の名詞32語の複数形には専用音声があります。選択した形の表記と優先発音で録音を解決し、録音がない形を基本形の音声で置き換えません。

## 参考画像

任意の画像リストフィールド、非公開の画像アップロード、詳細ギャラリーを追加します。両言語モジュールにライセンス表記付きの参考写真を同梱し、すべてのレイヤーで同じフィールドを提供します。

## 文全体の直接録音

同梱文は直接生成した文全体の録音を結合音声より優先します。新しい文や録音のない文には、構成要素の PCM と選択した活用形を順序通りに使うホストの結合処理を適用し、派生形の欠落を基本形で代用しません。対象は厳選パックであり、辞書の全項目や任意のユーザー作成文ではありません。 音声 `gJx1vCzNCD1EQHT212Ls` による新規の文録音を45件同梱します。日本語は仮名124クリップを再生成し、ローマ字ではなく仮名・漢字を送信します。モデル、速度、類似度、シード、音声の出典を記録します。

## 語彙の参考写真

厳選された語彙カード63件に参考写真を同梱しました（画像ファイル55件）。具体的な名詞すべてと、視覚的に明確な動作・性質を対象とし、文法・代名詞・その他の抽象概念には誤解を招く穴埋め画像を付けません。花/鼻、橋/箸、雨/飴、紙/髪/神などの日本語同音異義語には別々の画像を割り当てています。既存のカード詳細ギャラリーと画像全体のプレビューからローカル画像を読み込みます。出典の題名、作者、画像ごとの Creative Commons またはパブリックドメインのライセンス、チェックサムは[画像カタログ](../../data/library/assets/images/catalog.json)と[写真のクレジット](../../data/library/assets/images/LICENSE.md)に記録しています。ユーザー独自のカード画像は、プロバイダーの再読み込み後もホストによって保持されます。

## 語彙のイラスト

同梱されるすべての語彙カードに、それぞれ固有の色鉛筆・水彩調の生成イラストを追加しました（160件）。具体的な物、動作、抽象概念を説明する場面を、既存のカード詳細ギャラリーと画像ポップアップに表示します。従来の出典写真は置き換えました。[画像カタログ](../../data/library/assets/images/catalog.json)に生成元、画風、切り出し情報、チェックサム、カードとの対応を記録し、[画像ライセンス](../../data/library/assets/images/LICENSE.md)に同梱画像の扱いを記載しています。画像はローカルから読み込まれ、プロバイダーの再読み込み時もユーザー独自の画像はホストが保持します。

## 身近なものの語彙

家具、衣類、日用品、食べ物の名詞15件に、4言語の意味、発音リンク、専用録音、「身近なもの」のデッキを追加しました。英語の可算名詞には録音付きの複数形変換を用意し、fish は同形複数、rice は不可算名詞として扱います。日本語の初級者向け表記では、テーブルやコートで使う長音符「ー」を含め、完全な読みを個々のかなへリンクします。

## 食べ物と体の語彙

食べ物16件と体の部位16件、計32件のイラスト付き名詞に、4言語の意味と「食べ物」「体」の学習デッキを追加しました。英語には feet、teeth、potatoes、有声子音を持つ mouths など25件の録音付き数変換を用意し、鶏肉、牛肉、バター、肌などの不可算名詞の意味には複数形を設けません。日本語では個々のかなへ至る完全なリンクを保ち、「あし」の足と脚の意味を別々の定義に分け、発音入力が同じ場合は既存のネイティブ音声を再利用します。各言語に個別に作成した例文4件を追加し、直接生成したニューラル録音を、構成要素の録音をそのまま連結する代替音声より優先します。すべてのイラストを従来の言語別の画風でローカルに同梱しています。

## レビュー修正と録音一覧

録音メタデータを小さなマニフェストと、文字・語彙・活用形・文・文の合成録音別のチェックサム付き一覧に分割しました。音声データ、音声とリクエストの来歴、検索優先順位を維持します。参照インポートは同梱言語情報を読み、解除処理は失敗後も全登録を解除します。辞書エラー時は応答を破棄し、参照データの読み込みを再試行できます。設定と生成画像の説明も更新しました。

## 明示的なカタログ正規化と文の合成録音一覧

カタログ読み取りは言語プロバイダーから正規化方式を受け取ります。英語は NFC、日本語は NFKC を使用し、共通検索コード内の言語分岐を除去しました。文の合成録音一覧を `sentence-compositions` に改称し、各項目は構成要素のクリップを順番に連結した実際の同梱録音を表します。直接生成したニューラル文録音は別一覧に保持し、再生時に優先します。

## 画像ラベルの翻訳と中立的なファイル名

画像ファイル名と ID は SHA-256 ハッシュを使用し、元シートの識別子も出典のハッシュを使用します。カタログのメタデータはカードに既存の意味からドイツ語・英語・インドネシア語・日本語のラベルを提供します。表示ラベルと中立的な保存識別子を分離しました。画像データとカード ID は維持し、コンテンツ改訂ですべての画像参照を更新します。

## 使用方法

ElevenLabs合成を設定可能な独立モジュールへ移します。Studyは保存済みグローバルカードに言語ごとの任意の声を使用し、個人・クラスカードは上限付きアップロードとマイク録音を受け付けます。既存の構成カード音声を連続結合する代替機能を維持し、管理者は編集時にグローバル音声を再生成できます。

## Study有効化の修正

同梱音声の削除時に英語と日本語の実際のコンテンツパックのバージョンを上げます。有効化の失敗を返す前に他のモジュールの再構築を完了し、同意ルートの登録済みフローを維持します。

## すべての録音を再生成

パッケージ内の 331 件の録音を、この言語に設定された ElevenLabs の声で再生成しました。既存の読み、カード識別子、開始前の無音、間を設けた文の音声合成を維持します。生成ツールは環境変数の認証情報、再開可能な API 応答キャッシュ、ファイルの原子的な置き換えを使用し、パッケージに認証情報を含めません。一覧、帰属表示、コンテンツ改訂、整合性ハッシュも新しい録音に合わせて更新します。

## 最終レビューと無効な言語へのアクセス

アンインストールでは学習内容を保持する場合も音声設定を削除します。無効化するとモジュールのルート、静的 UI、プロバイダー登録を解除します。設定は無効化と再起動をまたいで保持し、有効な間だけ提供します。Cognis は稼働中の言語プロバイダーに基づいて保存済みスキーマ・カード・メディアへのアクセスを制限し、再有効化で復元します。参照検索は同一の出典識別子を統合し、元レコード、読み順、意味を保持します。同梱文は構成要素と同一の PCM 合成録音を優先し、直接録音も別途保持します。音声生成前に正規化済みの文字種と長さを検証します。KanjiVG の失敗応答は破棄し、長音符にも対応します。
