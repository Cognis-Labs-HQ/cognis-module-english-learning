# テーマ別の練習

**機能ブランチ:** `feature-expand-themed-practice`

## 文脈に沿った練習

食べ物と飲み物、過去の出来事、進行中の動作、場所と移動の4つの初期デッキを追加。既存の23文と、それらに結び付いた意味や文法形式を集中的に練習できます。

## より明確なイラスト

曖昧さや切り抜きの不備があった8点を差し替えます。動詞pleaseの意味を正しく表し、隣の画像の混入を除去。完結した場面で程度・結果・追加の意味を明確にします。

## 文脈に沿った使い方

各言語の説明と例で、冠詞の選択、対比、条件、絵が示す語義を明確にします。新しく確認した傘の場面で、in caseが表す事前の備えを示します。

## 旅行の語彙

旅行に役立つ語彙十二語に、確認済みの画像と活用形、構成語を関連付けた例文八つ、各言語対応の練習デッキ二つを追加します。旅行の新しい音声は同梱していません。

## 食事の練習

既存の語彙と構成語の音声をそのまま使い、食事に関する多様な例文六つと練習デッキを追加します。合成した音声は技術的な整合性を確認していますが、聴取による検証は行っていません。
